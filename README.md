# 🦯 IoT Blind Stick

An IoT-based Smart Blind Stick designed to help visually impaired people navigate safely by detecting obstacles and providing instant alerts. The project uses sensors and a microcontroller to improve mobility, safety, and independence.

## 📌 Features

- 🚶 Real-time obstacle detection
- 📏 Distance measurement using Ultrasonic Sensor
- 🔔 Buzzer alert for nearby obstacles
- 💡 LED indication
- 🌐 IoT-enabled monitoring (if applicable)
- 🔋 Portable and low-power design
- 🛠 Easy to build and cost-effective

---

## 🛠 Components Used

- Arduino Uno / NodeMCU (ESP8266/ESP32)
- Ultrasonic Sensor (HC-SR04)
- Buzzer
- LEDs
- Jumper Wires
- Breadboard
- Battery/Power Supply

---

## ⚙️ Working

1. The ultrasonic sensor continuously measures the distance to obstacles.
2. If an obstacle is detected within the predefined range, the controller activates:
   - 🔔 Buzzer
   - 💡 LED indicator
3. The user is alerted and can avoid the obstacle.
4. If IoT functionality is included, sensor data can also be transmitted over Wi-Fi for remote monitoring.
